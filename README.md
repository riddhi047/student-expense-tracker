Student Expense Tracker

A beginner-friendly Python project that calculates total expenses and average spending.

Features

- Takes food, travel, and other expenses as input.
- Calculates total expenses.
- Calculates average spending across the three expense categories.

Technologies Used

- Python

How to Run

Run "main.py" using a Python compiler or IDE, enter your expenses, and view the total and average.
